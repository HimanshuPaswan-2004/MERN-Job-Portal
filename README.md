# JobPortal – MERN Stack Job Portal

A full-stack Job Portal application built with the MERN stack.

## Features Implemented
- **Day 1-2: Authentication & Setup**: User registration and login (JWT).
- **Day 3: Company Management**: Creating and managing company profiles.
- **Day 4: Job Management**: Creating and managing job postings.
- **Day 5: User Profiles & Applications**: Edit Profile functionality, My Applications UI, and Navbar routing updates.

## Tech Stack
- **Frontend**: React.js
- **Backend**: Node.js, Express.js
- **Database**: MongoDB

## Structure
- `frontend/` (React Frontend)
- `backend/` (Node.js + Express Backend)

For detailed folder structure refer to documentation.
